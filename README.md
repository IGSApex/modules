# SPT Modules

Client-side modules providing core SPT functionality.

## Included Modules

| Module | Purpose |
| --- | --- |
| SPT.Common | Shared utilities |
| SPT.Core | Required game patches |
| SPT.Custom | Game enhancements |
| SPT.Debugging | Debug utilities |
| SPT.PrePatch | Early game patches |
| SPT.Reflection | Reflection utilities |
| SPT.SinglePlayer | Single-player simulation |

These are core client components and do not appear as optional mods in the launcher's Mod Manager.
